## 0. 背景：当前采样制导为什么在跟踪中不可靠

### 0.1 现实现

`uav_guidance_node` 的航向产生方式（`uav_guide/src/guidance.cpp::build()`）：

```
from = closest_index(planed_path, 本机位置)          # 最近点
idx  = find_sample_index(path, from, first_zero_curvature, eps=1e-4)   # 首个 |κ| <= eps 的点
heads = enu_yaw_to_heading_deg(path[idx].yaw)         # 纯映射：罗盘度 = 90 - ENU yaw
```

即"**自本机起，路径上第一个曲率为 0 的点**"的航向。

### 0.2 现场实测的一条计划（真实 `aoa/uav/planed_path` 单条消息，48 点）

| 段 | 索引 | 点数 | 点间距 | ENU yaw | 罗盘航向 | κ |
|---|---|---|---|---|---|---|
| 弧1（右转 **8.27°**，R=500） | 0–19 | 20 | 3.851 m | 184.39° → 176.12° | 265.6° → 273.9° | −0.002 |
| 直段（**824 m**） | 20–28 | 9 | 91.559 m | 176.117° 恒定 | 273.9° 恒定 | 0 |
| 弧2（右转 **≈186°**） | 29–47 | 19 | 82.090 m | 166.83° → 359.59° | 283.2° → 90.4° | −0.002 |

- 起点 (−4386.32, 990.93)，终点 (−5232.15, 2044.51)：直线位移 **1351 m**，但计划全长 **≈2456 m**。
- 本机当前航向 = 路径首点 yaw = ENU 184.39° = 罗盘 **265.6°**。
- 采样结果：`sample#20` → heads = **273.9°**，与当前航向只差 **8.27°**。
- 计划里真正的大转弯（弧2，186°）位于**路径末端、约 900 m 之外**。

> 实测提示：用 `ros2 topic echo`（不带 `--once`）抓 14 s 会得到 26 条消息首尾相连（1248 = 26×48 点），别误读成一条超长路径。

### 0.3 三个失效点

| # | 失效点 | 后果 |
|---|---|---|
| 1 | 参考点距离由**路径形状**决定（实测 73 m ~ 900+ m），不是常数 | 指令的"增益"随段变化，无法用一套参数覆盖 |
| 2 | 参考点是**离散索引**上的点，且在段边界切换 | 指令在段边界跳变；点距 82~91 m 时跳变更明显 |
| 3 | 只看"第一个"零点，**永远看不见更远的转弯** | 末端 186° 转弯从未被指令表达 → 表现为 heads 近乎恒定 |

**结论**：heads 计算链路（`90 − yaw` 的纯映射）没有问题；问题在**"选哪个点"**。这也解释了为什么"从首点扫、取第一个 κ 非 0→0 交界点"的改法不会改变现象——对这条路径它与现实现选中同一个点（idx 20）。

## 1. 设计目标 / 非目标

### 目标
1. 参考点距离固定，指令是状态的**连续函数**（无段边界跳变）。
2. 前视 L1 距离内的路径形状可见，**能提前表达转弯**。
3. 有解析的稳定性保证（阻尼比、自然频率可预先计算）。
4. 与本机的盘旋能力（R=500 m）**显式耦合**：不满权限、可预测饱和行为。
5. 只替换"航向产生方式"；不改变消息格式、频率、QoS 与模式门控。

### 非目标
- ❌ 不改 `mqtt_control_bridge` 的**纯翻译器**语义（5 Hz 逐帧透传）。
- ❌ 不动 `aoa/uav/guidance` 的字段与频率；不动 `nav_mode` 门控。
- ❌ **不修复"坏计划"**：L1 忠实跟踪给定路径。当前计划末端 186° U 形转弯的根因在 `decision.goal.yaw`（到达航向 90.4° 与进场方向 273.9° 相差 176°），需单独排查（见 §9）。
- ❌ 不做速度控制（`fly_speed_mps` 仍是常量占位）。

## 2. 原理

### 2.1 L1 制导律

设本机位置 P、当前航向 ψ、地速 V；在路径前方取参考点 P_L1（**沿路径弧长 = L1**）。

```
θ_LOS = atan2(P_L1.y − P.y, P_L1.x − P.x)      # 视线方向（ENU）
β     = wrap(θ_LOS − ψ)                        # 偏差角，正 = 参考点在航向左侧
a_cmd = 2·V²/L1 · sin β                        # L1 侧向加速度指令（垂直于速度）
```

等效为转弯角速率与曲率：

```
ω_cmd = a_cmd / V = 2·V/L1 · sin β
κ_cmd = ω_cmd / V = 2·sin β / L1                # 期望曲率 (1/m)
```

### 2.2 几何解释（也是本方案与"固定盘旋半径"的接口）

"从当前位姿出发、切于当前速度、且通过 P_L1"的圆弧，其半径由**弦切角 = 圆心角之半**给出：

```
R_cmd = D / (2·sin|β|),   D = |P_L1 − P|  ≈ L1
```

- 该圆弧的圆心角 = 2|β|，转向方向 = sign(β)。
- 圆弧**出口航向** = `ψ + 2β`（在出口切点处与路径相切）。
- 因此 L1 律本质上就是"**飞一条恰好通过前视点的圆弧**"，与 Dubins 车型的运动学天然一致。

### 2.3 L1 = 1000、R = 500 为什么自洽

| \|β\| | R_cmd = L1/(2 sin\|β\|) | 是否触及能力上限 R_c=500 |
|---|---|---|
| 5° | 5736 m | 否 |
| 30° | 1000 m | 否 |
| 60° | 577 m | 否 |
| **90°** | **500 m** | **恰好到边界** |
| > 90° | < 500 m | 是（饱和） |

即 **L1 = 2·R_c** 意味着：整个可用范围（|β| ≤ 90°）内控制律都不超权限，且刚好在 |β|=90° 处到达边界。横向误差在 ±L1 以内时完全在包线内。

### 2.4 为什么不是"始终以 R_c 盘旋"（bang-bang）

若把"固定盘旋半径"理解为"一直以 500 m 转"，控制律会在"转/不转"之间反复切换（滑模抖振），路径附近持续摆动，且对 5 Hz 出站流不友好。本方案把 R_c 用作**能力上限（κ 饱和）**，由 L1 距离提供连续增益 → 平滑、可控、可分析。

## 3. 算法流程

每周期（`guidance.publish_rate_hz`，现场 5 Hz）执行：

| 步 | 内容 | 关键要求 |
|---|---|---|
| ① | 把本机 (x,y) 投影到路径折线：遍历求最近段与最近点，**在段内线性插值** | 不要用整数索引；插值才能消除 82~91 m 点距造成的抖动 |
| ② | 得到沿路径里程 `s0`（投影点的弧长坐标） | 弧长由相邻点折线长度累加 |
| ③ | 沿路径从 `s0` 前进 **L1**，插值得到参考点 P_L1（及该点航向 ψ_L1） | 剩余弧长 < L1 → 取路径末点，置 `near_end` |
| ④ | 计算 `θ_LOS`、`β = wrap(θ_LOS − ψ_uav)` | ψ_uav 取 `aoa/uav/state` 的朝向；建议对 β 做轻量低通或死区 |
| ⑤ | `κ_cmd = 2·sin β / L1`，**饱和**：`κ_cmd ← clamp(κ_cmd, −1/R_c, +1/R_c)` | R_c = `turn_radius_m` |
| ⑥ | `ψ_cmd = wrap(ψ_uav + κ_cmd·V·T_lead)`；输出 `heads = enu_yaw_to_heading_deg(ψ_cmd)` | T_lead = 飞控航向环时间补偿 |

补充规则：

- **死区**：`|β| < beta_deadband` → `κ_cmd = 0`（抑制出站流无意义抖动）。
- **限幅**：`|ψ_cmd − ψ_uav| ≤ ω_max·T_lead`，`ω_max = V/R_c`（由 ⑤ 自动满足，外加一道防御）。
- **异常保护**：`|β| > 90°`（参考点在本机侧后方，多半是投影跳变或路径倒退）→ 指令维持在上一周期值，并置告警计数；连续 N 周期则退化为"朝参考点直飞"。
- **高度解耦**：`fly_height` 由既有配置决定（建议按既定设计用 `target_z`），与 L1 无关。
- **L1 点的两种取法**：
  - **弧长法（默认，推荐）**：沿路径累计弧长 L1。转弯处参考点更深地落进弯里 → **提前性更强**，正是本方案要的效果。
  - 欧氏法（备选）：取与弦长 L1 对应的路径点。直线段两者等价，弯道处提前性弱一些。

## 4. 参数

新增于 `uav_guide/config/uav_guide.yaml` 的 `guidance:` 段：

| 参数 | 默认 | 单位 | 作用 | 调整方向 |
|---|---|---|---|---|
| `l1_distance_m` | **1000** | m | 前视弧长（参考点距离） | ↓ 贴路径更紧但易饱和振荡；↑ 更平滑但切角增多 |
| `turn_radius_m` | **500** | m | 盘旋能力上限（κ 饱和用） | 应与机型实际最小盘旋半径一致；偏小会指令过不了弯 |
| `lead_time_s` | **1.0** | s | 飞控航向环时间补偿 | 飞控迟钝 → 调大；出现振荡 → 调小 |
| `speed_mps` | 50.0 | m/s | 计算 ω 用；优先用实测地速 | V 错则转弯半径错 |
| `beta_deadband_deg` | 0.5 | ° | 指令死区 | 出站流抖动大 → 调大 |
| `end_shrink_ratio` | 1.0 | — | 末端 L1 收缩比例（0 = 不收缩） | 末段增益过低 → 调小 |

`l1_distance_m` 与 `turn_radius_m` 的默认值满足 **L1 = 2·R_c**（见 §2.3），建议保持该比例关系。

## 5. 稳定性与性能（可直接用来定参数）

对直线路径小偏差线性化（横向误差 y、航向偏差 ψ），L1 律给出二阶系统：

```
ÿ + (2V/L1)·ẏ + (2V²/L1²)·y = 0
```

```
ζ  = 1/√2 ≈ 0.707        # 阻尼比恒为 0.707，与速度无关（L1 的核心优点）
ωn = √2·V / L1           # 自然频率随 V/L1 线性变化
```

取 **V = 50 m/s、L1 = 1000 m**：

| 指标 | 值 | 说明 |
|---|---|---|
| ω_n | 0.0707 rad/s = **4.05 °/s** | 闭环带宽 |
| 衰减时间常数 1/(ζω_n) | 20 s | |
| 4τ 调节时间 | ≈ 80 s（≈4 km 航程） | 阶跃横向偏差的收敛时间 |
| 超调量 | exp(−πζ/√(1−ζ²)) = **4.3 %** | 与小偏差线性化一致 |
| 特征收敛长度 V/ω_n | **707 m** = L1/√2 | 误差修正的"距离尺度" |
| 本机最大转弯角速率 V/R_c | 0.1 rad/s = **5.73 °/s** | 能力上限 |
| 权限余量 | 5.73 / 4.05 = **1.41 倍** | 不饱和 |
| 180° 转弯耗时 / 弧长 | 31.4 s / 1570 m = πR_c | 用于评估末端 U 形的可执行性 |

**工程含义**：L1 = 1000 m 是"不饱和前提下最紧"的取值；若要更紧贴路径，需同时放宽 `turn_radius_m`，或接受饱和（饱和期间表现为"以 R_c 转向参考点"，仍有界）。

## 6. 边界情况清单

| 场景 | 处理 |
|---|---|
| 路径为空 / 未成功 | 维持既有行为：不发布陈旧指令，限流告警 |
| 剩余路径 < L1 | 参考点 = 路径末点；置 `near_end`，可选按 `end_shrink_ratio` 线性收缩 L1 |
| 本机已越过路径末点 | 用末点航向（等效 fail-safe），并计数告警 |
| 投影点不唯一（路径自交/近折返） | 取"前进方向一致"的候选段；无候选则退化为朝参考点直飞 |
| 本机位姿不可用（`aoa/uav/state` 掉线） | 跳过本轮（不发布），与现实现一致 |
| 地速 V 异常（< 1 m/s 或缺失） | 回退 `speed_mps` 常量 |
| 路径跳变（重新规划导致） | 由 ① 的插值 + ⑥ 的变化率限幅吸收；β 跳变超阈值则本周期保持 |

## 7. 与现有架构的接口

**保持不变**：

- 输入：`aoa/uav/state`（位姿 + 地速）、`aoa/uav/planed_path`（latched，48~N 点）、`aoa/target/state`
- 输出：`aoa/uav/guidance`（`uav_guide/msg/Guidance`），**严格 5 Hz** 单一定时器
- 下游：`mqtt_control_bridge` 纯翻译（5 Hz 逐帧）→ MQTT `set_cruise_mode/set_fly_head/set_fly_height`
- 模式门控：`aoa/uav/nav_mode`（`auto`/`setpoint`/`guidance`）语义与代码路径不变

**新增/变更**：

- `heads` 的产生方式：由"零点采样"改为"L1 解算"。
- 建议以 `guidance.heads_source: l1` 新增可选值（保留 `sample_yaw` / `bearing_to_sample`），便于**现场 A/B 对比**与回退；是否保留旧值由裁决决定（注意：MQTT 协议层的"不兼容旧值"约束不适用于此内部测试开关）。
- 观测新增（可选）：`β`、`|κ_cmd|`、是否饱和、参考点索引与里程——建议随日志打印（限流），便于现场定性。

## 8. 验收与测试计划

### 8.1 离线仿真（先做，最省成本）
1D/2D 横向动力学 + 按 §3 的流程，验证：
- ζ ≈ 0.707、超调 ≈ 4.3 %、稳态横向误差 → 0；
- 扫描 `L1 ∈ {700, 1000, 1500}`、`T_lead ∈ {0.5, 1, 2}`，产出参数建议表；
- 饱和测试：初始横向偏差 > L1。

### 8.2 隔离域人造路径（`ROS_DOMAIN_ID=77`，不动真机）
路径族（可复用已有人造路径发布脚本）：

| 用例 | 期望 |
|---|---|
| 直线 + 200 m 横向偏置 | ~25 s 内收敛，无持续振荡，超调 ≤ 5 % |
| 单圆弧（R=500） | 参考点始终在弧上，指令平滑 |
| S 形（左右各 90°） | 无过冲切换抖动 |
| **首段直段 → 弧 → 直段** | L1 应提前表达弧段（对照：现实现会停在直段起点） |
| **末端大转弯（当前现场形状）** | 指令应在到达切点**之前**开始积累 |

### 8.3 真机
- 阶梯横向偏置短路径，观察收敛与振荡；
- 长航程跟踪：统计横向误差、`set_fly_head` 变化率、出站频率是否仍恒定 5 Hz（不得出现突增）。

### 8.4 回归
- `uav_guide` 现有 20 项单测 + 新增 L1 用例（几何、饱和、末端、异常保护）；
- 全仓 41 项单测保持 0 失败；
- `mqtt_control_bridge` 出站语义不受影响（三类 mode 的映射表与计数）。

## 9. 风险与局限

| 风险 | 说明 | 缓解 |
|---|---|---|
| **不修复坏计划** | 当前计划"先直飞 824 m 再末端 186° U 形"的根因是 `decision.goal.yaw`（到达航向与进场方向差 176°）。L1 只会让它**提前开始转**，计划本身仍然绕远（2456 m 换 1351 m 位移） | 单独立项排查拦截点到达航向的算法 |
| 依赖 V 的准确性 | ω = V·κ，V 错则转弯半径错 | 优先用 `aoa/uav/state` 实测地速；异常时回退常量 |
| 内环滞后 | §5 假设加速度即时可达；实际飞控航向环有滞后 | `lead_time_s` 按内环时间常数标定，并在真机复核 ζ |
| 切角是固有特性 | L1 的贴路径精度 ~L1 量级 | 需要更紧时减小 L1 并同步放宽 R_c |
| 参考点越界 | 投影跳变/路径倒退会导致 β 突变 | §3 的 β>90° 保护 + 变化率限幅 |
| 与"计划持续重规划"的耦合 | loop_node 每状态周期重规划，L1 点随新计划移动 | L1=1000 m ≫ 单周期位移（≈10 m @5 Hz），参考点变化平滑；无需额外处理 |

## 附录 B：与现实现的行为对照

| 情形 | 现实现 `first_zero_curvature` | L1（本方案） |
|---|---|---|
| 路径首段为圆弧（现场常见） | 取该弧出口点航向（距离不定） | 取前视 L1 点，指令为连续函数 |
| 路径首段为直段 | 返回直段起点 → heads ≈ 当前航向（**直飞**） | 前视点落在后续弧段内 → 提前给出转弯指令 |
| 末端大转弯 | **不可见**，需飞到弧附近才被采样 | L1 点在转弯发生前就进入弧内 → 提前表达 |
| 段边界 | 离散索引切换 → 跳变 | 插值 → 平滑 |
| 稳定性 | 无解析保证 | ζ = 0.707、ω_n = √2V/L1 |

> 注：当路径首段就是圆弧时（现场实测那条 48 点计划），两种方法的**选中点恰好相同**（idx 20，heads 273.9°）。因此 L1 的价值不在"改掉某一个点的选择"，而在于把参考点距离**变成常数**、把指令**变成连续量**，并让**前方 L1 内的转弯可见**。
